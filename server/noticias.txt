Zombie + Event Bug: de hora em hora

Horário de São Paulo. Um evento por hora, alternando:
- Horas pares (00, 02, 04... 22): Zombie Event
- Horas ímpares (01, 03, 05... 23): Event Bug

Zombie Event
- TP no temple aberto por 5 minutos (antes 2)
- Mínimo 4 jogadores
- Winner: taça + arma Vip9 aleatória + 100 gold nuggets

Event Bug
- Aviso 5 min antes. Spawn perto do temple
- 15 minutos para matar
- Reward compartilhado perto do kill: arma+50 nuggets OU set Master

Digite !notice no jogo para ver este resumo.
